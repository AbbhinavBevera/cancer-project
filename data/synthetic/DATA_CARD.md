# Data card: SYNTHETIC tumour-vs-normal expression dataset

> **This is not real patient data.** It was generated by
> `src/make_synthetic_dataset.py` (seed 7). Do not report anything learned from it
> as a biological or medical finding. Its purpose is to let people and AI agents
> test code against a case where the correct answer is known.

## Files

| File | What it is |
|------|-----------|
| `synth_counts.csv` | Raw RNA-seq-style read counts. Rows = samples, columns = genes, last column `label`. Use this to practise normalisation. |
| `synth_expression_log2cpm.csv` | Same data as log2(CPM + 1). Pipeline-ready: `python src/train.py --data data/synthetic/synth_expression_log2cpm.csv` |
| `synth_metadata.csv` | Per-sample info: `sample_id, label, condition, batch, library_size` |
| `ground_truth_biomarkers.csv` | The 40 genes that were truly made different between classes, with true log2 fold-change and direction |

## Size and labels

- 240 samples (132 tumour = 1, 108 normal = 0), 1,500 genes (`SYN_0001` to `SYN_1500`)
- Gene names are deliberately fake so nothing can be mistaken for a real gene finding

## How it was built (what makes it realistic)

- Counts from a negative binomial distribution (overdispersed, like real RNA-seq)
- Each sample has its own sequencing depth (library size varies about 130k to 430k)
- 40 true biomarkers (24 higher in tumour, 16 lower), log2 fold-change 0.25 to 0.9
- Some true biomarkers are lowly expressed, so they are hard to detect
- A batch effect on about 15% of genes, unrelated to disease
- Batches are slightly unbalanced across classes (a mild confounder to watch for)

## Baseline results with the shipped pipeline (synthetic data only)

Use these as a regression check. Small differences (about +/- 0.03) between
scikit-learn versions are normal.

| Model | CV accuracy | CV recall | CV ROC-AUC |
|-------|------------|-----------|-----------|
| Logistic Regression (L1) | 0.854 | 0.877 | 0.937 |
| Linear SVM | 0.813 | 0.840 | 0.885 |
| Random Forest | 0.896 | 0.972 | 0.978 |

Best model by CV ROC-AUC: Random Forest. Test set (only 48 samples, so noisy):
accuracy 0.917, recall 1.0.

Biomarker recovery (`python src/validate_biomarker_recovery.py`): 12 of the
top 15 reported genes are true biomarkers (precision 0.80), all 12 with the
correct direction; 30% of all 40 true biomarkers recovered in the top 15.

## Good uses

- Smoke-testing the pipeline and CI
- Checking that changes do not introduce data leakage (see `docs/AGENT_PLAN.md`, Phase 4)
- Practising normalisation and batch handling
- Measuring whether a biomarker method finds known truth

## Not good uses

- Any claim about real cancer biology
- Tuning hyperparameters to "win" and then quoting the numbers as results
- Anything in an application, certificate or paper without a clear "synthetic" label

## Limitations

Real data has correlated gene modules, non-uniform noise, sample outliers and
messy labels that this generator does not model. Effect sizes here are arbitrary.
The test split is small. Good performance here does not predict performance on real data.
